各文档说明
1. Taming SQL Complexity: LLM-Based Equivalence Evaluation for Text-to-SQL

来源：arXiv:2506.09359

主题：利用 LLM 评估 SQL 的语义等价和“弱”语义等价，分析 SQL 等价与不等价的常见模式，讨论 LLM 评估的挑战。

对判题的价值：直接对应判题核心——当用户 SQL 与标准答案写法不同但逻辑等价时的判断方法。

2. JudgeSQL: Reasoning over SQL Candidates with Weighted Consensus Tournament

来源：arXiv:2510.15560

主题：提出基于推理的 SQL 判题模型，通过结构化推理和加权共识锦标赛机制，从多个候选 SQL 中选出正确答案，实现可解释的判断。

对判题的价值：提供从多候选结果中选择最优答案的判题框架。

3. SQLens: An End-to-End Framework for Error Detection and Correction in Text-to-SQL

来源：arXiv:2506.04494

主题：端到端的语义错误检测与修正框架，整合数据库和 LLM 的错误信号，精确定位 SQL 各子句中的语义错误并指导修正。

对解析的价值：为错误定位和修正建议生成提供方法论。

4. GradeSQL: Outcome Reward Models for Ranking SQL Queries

来源：arXiv:2509.01308

主题：训练 Outcome Reward Models（ORM），根据语义正确性为生成的 SQL 查询分配效用分数，用于对候选答案进行排序和评分。

对判题的价值：为 SQL 答案的自动评分与排序提供模型参考。

5. Large Language Models for Automated Personalized Feedback in SQL Education

来源：INFUS 2025 / Springer

主题：使用 GPT-4o 评估学生 SQL 查询，生成详细的、个性化的批评意见并附带置信度指标，实现自动化个性化反馈。

对解析的价值：直接指导解析反馈的生成方式和质量评估。

6. CodeLens: A Generative AI Framework for Automated Feedback on SQL Assignments

来源：ACM / SIGMOD 2025

主题：AI 辅助框架，让 LLM 像讲师一样提供引导性反馈而不直接给出答案，检测语义错误并生成有帮助的反馈。

对解析的价值：提供“引导式反馈而非直接给答案”的解析策略参考。

7. 如何在 PHP 中精准比对 PDO 查询结果集

来源：php.cn (2026-03-25)

主题：实现“集合语义”的结果集比对，将结果集转换为标准化、可哈希、可排序的结构，通过哈希值数组排序比对实现行列完全一致的判断。

对判题的价值：提供结果集比对的具体实现代码参考。

8. Redefining Text-to-SQL Metrics by Incorporating Semantic and Structural Similarity

来源：Nature Scientific Reports (2025-07-01)

主题：提出 SQL 查询相似性评估指标，从语义（字符串）和执行结果两个层面评估 SQL 相似度，支持部分正确性、结构差异和语义等价的精细化评估。

对判题的价值：提供细粒度评分机制，支持对部分正确的答案进行打分。

9. What Do You Mean? Using LLMs for Semantic Evaluation of NL2SQL Queries

来源：University of Waterloo (2025-04-23)

主题：提出混合框架，结合执行结果验证与 LLM 语义分析，先用执行准确率验证，再用 Qwen 2.5 Coder 执行语义等价检查，消除执行结果的假阳性。

对判题的价值：提供“执行验证 + LLM 语义检查”的混合判题流程。

10. Effectiveness of Prompt Optimization in NL2SQL Systems

来源：SIGMOD 2025 / NOVAS Workshop

主题：研究如何通过提示优化提高 NL2SQL 系统精度，提出多目标优化的 Prompt 优化框架。

对判题/解析的价值：指导 LLM 判题和解析的 Prompt 设计，提高判题准确性。
